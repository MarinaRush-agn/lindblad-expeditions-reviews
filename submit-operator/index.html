Submit an Operator

This page explains what it takes for an Antarctic expedition operator to be added to the ranking, and what it does not take.

Inclusion criteria

  • Operates Antarctic voyages in the current season
  • Publishes fleet capacity and ice class for every ship sailing to Antarctica
  • Publishes pricing for its Antarctic itineraries
  • Discloses its IAATO membership status, one way or the other

What to send

Email the fields below to the address on the contact page, with sources for each:

  • Operator name and official website
  • Fleet list: ship name, total berths, Antarctic-specific passenger limit if different, ice class
  • Published price range for Antarctic sailings, and what it includes
  • IAATO membership status and, if a member, the year membership began

What submission does not do

Inclusion cannot be purchased. There is no fee for a listing, and submitting data does not influence where an operator lands in the ranking — only the published formula, applied to the submitted data, determines position. If the submitted figures don't hold up against a source this site can independently verify, the listing will not go live until they do.
